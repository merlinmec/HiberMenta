CRUD MVC em Java 8 com Hibernate e Mentawai, feito em 2023 para aprender a
stack que uso no trabalho (o Edu3 roda em Mentawai + Hibernate + JSP).

Mentawai é um framework MVC brasileiro, anterior ao Spring Boot, com
configuração em código em vez de XML. Este repo mostra o ciclo básico:
mapeamento Hibernate, actions do Mentawai e páginas JSP.
